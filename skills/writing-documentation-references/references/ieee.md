# IEEE

Assign bracketed reference numbers in first-citation order: `[1]`, `[2]`. Reuse a source's number. Add a passage locator when needed: `[1, p. 12]`. List references by number, not alphabetically. Follow the target publication's current template for detailed typography and author limits.

## Patterns

**Book**

[{Number}] {Initials Surname}, *{Book Title}*, {Edition}. {City, Country}: {Publisher}, {Year}.

**Journal article**

[{Number}] {Initials Surname}, “{Article title},” *{Abbreviated Journal Title}*, vol. {Volume}, no. {Issue}, pp. {Range}, {Month Year}, doi: {DOI}.

**Online page**

[{Number}] {Author or organization}, “{Page title},” {Site name}. Accessed: {Mon. Day, Year}. [Online]. Available: {URL}

Use an established journal abbreviation; never invent one. Substitute the appropriate article-number element when there is no page range. Record publication or update dates when available and follow the publication's online-source example for placement. Never guess access dates.

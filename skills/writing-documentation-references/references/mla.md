# MLA 9

Use author–page citations: `({Surname} {Page})`. When the author is named in the sentence, use `({Page})`. Do not invent pages for unpaginated sources. Alphabetize the **Works Cited** list; use hanging indents and double spacing in manuscripts.

Build entries from applicable core elements. A container is the larger work holding the source, such as a journal containing an article. Additional containers can identify a database or collection.

## Patterns

**Book**

{Surname}, {Given name}. *{Title}*. {Edition if relevant}, {Publisher}, {Year}.

**Article**

{Surname}, {Given name}. “{Article Title}.” *{Journal Title}*, vol. {Volume}, no. {Issue}, {Year}, pp. {Range}. {DOI URL or URL}.

**Web page**

{Surname}, {Given name}. “{Page Title}.” *{Website Title}*, {Publisher if distinct and applicable}, {Day Month Year}, {URL}.

Use title case for English titles. Omit unavailable elements rather than inserting empty fields. If no author is credited, begin with the title and cite a shortened title. Access dates can help identify undated or changeable web content. Consult the guide for organizational authors and multiple authors.

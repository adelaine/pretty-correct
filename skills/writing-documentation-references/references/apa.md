# APA 7

Use author–date citations and an alphabetized **References** list. For a formatted manuscript, double-space entries and use a 0.5-inch hanging indent.

## In-text patterns

- Parenthetical: `({Surname}, {Year})`; narrative: `{Surname} ({Year})`.
- Quotation: `({Surname}, {Year}, p. {Page})`. Without pages, use a paragraph number or section locator when available.
- Two authors: `({Surname} & {Surname}, {Year})`; use “and” in narrative citations.
- Three or more: `({First surname} et al., {Year})`, unless expansion is needed to avoid ambiguity.
- Same author and year: `{Year}a`, `{Year}b`, matched to reference-list order.

## Reference patterns

**Book**

{Surname}, {Initials}. ({Year}). *{Title in sentence case}* ({Edition other than first}). {Publisher}. {DOI URL if available}

**Journal article**

{Surname}, {Initials}. ({Year}). {Article title in sentence case}. *{Journal Title}, {Volume}*({Issue}), {Page range}. {DOI URL}

Use `Article {Number}` instead of pages when appropriate. Keep the issue number unitalicized. For articles without a DOI, consult the official examples: a routine academic database URL is generally omitted.

**Web page or online documentation**

{Author or group}. ({Year}, {Month} {Day}). *{Page title in sentence case}*. {Site name}. {URL}

Omit the site name when it is identical to the author. Use the available date precision. Include a retrieval date only for unarchived content designed to change over time: `Retrieved {Month} {Day}, {Year}, from {URL}`.

**Chapter in an edited book**

{Surname}, {Initials}. ({Year}). {Chapter title}. In {Editor initials} {Surname} (Ed.), *{Book title}* (pp. {Range}). {Publisher}. {DOI URL if available}

**Report**

{Author or group}. ({Year}). *{Report title}* ({Report number if supplied}). {Publisher}. {DOI URL or public URL}

Omit the publisher when identical to the author.

## Common exceptions

Use `n.d.` for no date. If no author is credited, move the title to the author position and use a shortened title in the citation, preserving the appropriate italics or quotation marks. Do not label a work “Anonymous” unless it is signed that way.

List up to 20 authors in a reference; for 21 or more, list the first 19, an ellipsis, and the final author. Use an ampersand before the last author when listing 2–20 authors. Preserve credited author order. Do not put a period after a DOI or URL.

# Chicago 18

Choose one system; do not mix note numbers with source reference numbers. Use title case for English titles and alphabetize bibliographies or author–date reference lists. Apply hanging indents in formatted lists.

## Notes and bibliography

Use superscript note numbers in text. Each new note gets a new number, even when citing a previously cited source.

**First book note**

{Given name Surname}, *{Title}* ({Publisher}, {Year}), {Cited page}.

**Shortened note**

{Surname}, *{Short Title}*, {Cited page}.

**Book bibliography entry**

{Surname}, {Given name}. *{Title}*. {Publisher}, {Year}.

**Journal bibliography entry**

{Surname}, {Given name}. “{Article Title}.” *{Journal Title}* {Volume}, no. {Issue} ({Year}): {Full page range}. {DOI URL}.

**Web bibliography entry**

{Author or organization}. “{Page Title}.” {Site name}. {Publication or revision date}. {URL}.

For an undated web page, supply the actual access date. Modern book citations no longer require publication place.

## Author–date

In text: `({Surname} {Year}, {Page})`.

**Book**

{Surname}, {Given name}. {Year}. *{Title}*. {Publisher}.

**Journal article**

{Surname}, {Given name}. {Year}. “{Article Title}.” *{Journal Title}* {Volume} ({Issue}): {Full page range}. {DOI URL}.

**Web page**

{Author or organization}. {Year}. “{Page Title}.” {Site name}. {Full publication or revision date}. {URL}.

For an undated page use `n.d.` as the year and add the actual access date. Use suffixes for same-author, same-year works as needed.

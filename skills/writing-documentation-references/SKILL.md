# Writing Documentation References

Connect claims to identifiable, retrievable sources. Default to APA 7; preserve a required or established style. These are distinct citation styles, not interchangeable formats or one universal international standard.

## Select a guide

Read only the guide for the selected style:

- [APA 7](references/apa.md): default; author–date citations and a References list.
- [MLA 9](references/mla.md): author–page citations and a Works Cited list.
- [Chicago 18](references/chicago.md): notes and bibliography, or author–date. Preserve the existing system; ask which system is required if the request only specifies Chicago and the document gives no indication.
- [IEEE](references/ieee.md): numbered citations for technical publications; apply the target publication's current instructions.

For another style, consult its authoritative guide before formatting. Do not relabel these patterns as a different style. When a requested edition differs, use that edition's rules.

## Apply citations

1. Gather source metadata from the work, publisher, or authoritative catalogue: credited creators, title, date, source type, container, edition or version, locators, and persistent identifier or URL.
2. Check that each source supports the associated claim. Distinguish reading a source from reading someone else's account of it. For secondary citations, follow the selected style and identify the work actually consulted.
3. Apply the relevant source pattern. Braces in patterns are replacement fields, not literal citation text. Markdown italics represent italics in the finished document. Omit inapplicable optional fields and clean up punctuation.
4. Place citations near the claims they support. Include a precise locator for quotations where available. Separate the complete article page range in a reference from the passage locator in a citation.
5. Check names, dates, titles, source versions, links, ordering, and correspondence between citations and references. Consolidate duplicates and distinguish same-author, same-year works according to the selected style. Apply its list heading, indentation, and spacing when the output format supports them.

## Source integrity

Never invent metadata, identifiers, links, quotations, or access dates. Explain missing essential information briefly and mark unresolved draft fields. A website copyright year is not evidence of a page's publication date. Cite the edition or version actually consulted, and verify that a DOI or URL identifies that resource when access permits.

Use neutral placeholders in reusable examples. Preserve actual source names and titles when citing real works; do not import personal or company context from unrelated tasks. Do not rewrite substantive claims merely to make an unsuitable source appear relevant.

The guides cover common cases, not every exception. Consult their official links for unusual resources, many-author rules, ambiguous metadata, or publication-specific requirements. If a linked guide cannot be inspected, state the verification limit rather than claiming full compliance. Return the requested citation edits and only material unresolved issues.

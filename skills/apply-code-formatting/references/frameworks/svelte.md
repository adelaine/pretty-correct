# Svelte

Import the maintained Svelte ESLint preset and compose the applicable language settings using its documented parser integration. Inspect Svelte and SvelteKit versions, compiler syntax, and generated configuration before choosing presets. Preserve the component parser and configure TypeScript through the supported nested parser options.

Use the maintained Svelte Prettier plugin and verify compatibility with any other formatter plugins. Keep framework-generated files out of lint/format targets while retaining generated types needed by the checker. Run the project's Svelte-aware checks and build for affected components.

Sources: [Svelte ESLint user guide](https://sveltejs.github.io/eslint-plugin-svelte/user-guide/) and [Svelte Prettier plugin](https://github.com/sveltejs/prettier-plugin-svelte). Recheck current owners, locations, and version requirements before applying examples.

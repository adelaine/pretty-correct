# Pretty Correct

A skill collection for applying standards.

Pretty Correct helps agents apply established standards and style conventions consistently. Each skill describes when it applies, provides practical patterns, and points to authoritative guidance for details and exceptions.

## Skills

| Skill | Purpose |
| --- | --- |
| [writing-documentation-references](skills/writing-documentation-references/SKILL.md) | Format and check citations and reference lists. Defaults to APA, with separate guides for APA, MLA, Chicago, and IEEE. |

## Using the collection

Open the relevant skill's `SKILL.md` for its scope and instructions. Read the supporting guide in `references/` for the standard or style you need. Follow any edition or publication requirements specified for the task, and consult the linked authoritative sources for cases beyond the bundled patterns.

Each skill folder contains its own guidance and supporting files; keep that structure intact when copying it into an agent's skill location. The patterns are practical aids and do not replace the applicable standard or style manual.
